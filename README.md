# Belajar SPA

## Deskripsi
Belajar SPA adalah aplikasi web berbasis Single Page Application (SPA) yang dirancang untuk siswa-siswi. Aplikasi ini menyediakan berbagai fitur interaktif dan responsif untuk mendukung proses belajar mengajar.

## Fitur
- **Login & Registrasi**: Pengguna dapat mendaftar dan masuk ke aplikasi dengan menggunakan username dan password yang aman.
- **Absen Harian**: Siswa dapat melakukan absensi harian dengan mudah.
- **Jadwal Pelajaran**: Menampilkan jadwal pelajaran yang terorganisir.
- **Pengumuman**: Menyediakan informasi terbaru dari guru atau admin.
- **Materi Belajar**: Akses ke materi belajar dalam bentuk PDF, PPT, atau video.
- **Tugas & Pengumpulan**: Manajemen tugas dan pengumpulan hasil kerja siswa.
- **Quiz/Ulangan**: Fasilitas untuk melakukan quiz dengan auto-grading untuk soal pilihan ganda.
- **Chat Room**: Ruang obrolan untuk interaksi antar siswa.
- **Forum Diskusi**: Tempat untuk berdiskusi dan bertanya jawab.
- **Profil**: Pengguna dapat mengedit informasi profil mereka.
- **Leaderboard**: Menampilkan peringkat aktivitas siswa.
- **Kalender Akademik**: Menyediakan informasi tentang kegiatan akademik.

## Teknologi
- **Frontend**: HTML5, TailwindCSS, dan Vanilla JavaScript (ES Modules).
- **Backend**: Firebase Realtime Database untuk penyimpanan data.
- **Notifikasi**: Menggunakan Telegram Bot untuk notifikasi admin.

## Instalasi
1. Clone repositori ini:
   ```
   git clone <URL_REPOSITORI>
   ```
2. Masuk ke direktori proyek:
   ```
   cd belajar-spa
   ```
3. Install dependensi yang diperlukan:
   ```
   npm install
   ```
4. Jalankan aplikasi:
   ```
   npm start
   ```

## Penggunaan
- Akses aplikasi melalui browser dengan membuka `index.html`.
- Ikuti petunjuk di halaman untuk melakukan registrasi atau login.
